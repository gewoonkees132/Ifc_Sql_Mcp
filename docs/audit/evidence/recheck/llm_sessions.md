## What to fix in Revit before you re-export

1. **Export settings:** in the IFC export options, tick **"Export base quantities"**. I'd also tick "Export Revit property sets". This one change brings back areas, volumes and lengths.
2. **Rooms:** place and bound Rooms on every level, and make sure the export includes them. They should come through as IfcSpace.
3. **Materials:** give real materials to the wall, floor and window types that use the Default or Unnamed placeholders. Start with the generic walls ("Default Wall", 6,024 elements), then the concrete ("Default - Calcestruzzo") and the window/curtain-panel material.
4. **Fire ratings:** fill in the *Fire Rating* type parameter at least on fire doors, compartment walls and slabs. The exporter maps it to `Pset_*Common.FireRating`.
5. **Project Information:** enter the real project number and name.
6. **Type names:** rename the `1AR_MUR_PV001` and `1AR_MUR_PV007` wall types (and any others with the same problem) by retyping the name cleanly. That removes the hidden characters.
